# MovFlx Website

## Description
MovFlx is a website project developed during the Code Academy Full Stack Frontend Development course. The project aims to provide users with information about movies and TV shows, allowing them to explore and discover new content. The project was developed using HTML, CSS, JavaScript, and React.

## Features
- **Movies & TV Shows**: Users can search for information about movies and TV shows and discover new content based on their interests.
- **Simple User Interface**: A clean and intuitive design enhances the user experience.
- **Responsive Design**: The website is optimized for both mobile and desktop devices.

## Technologies Used
- **HTML5**
- **CSS3**
- **JavaScript**
- **React.js**
- **Git** (Version Control)
